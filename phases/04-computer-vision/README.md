# Phase 4: Computer Vision

> Von Pixeln zum Verstehen across image, video, and 3D.

## Diese Phase auf GitHub starten

**Voraussetzungen:** Phase 1 Lesson 12, Tensor Operations, and Phase 3 Lesson 11,
Introduction to PyTorch. The first demo needs only NumPy.

**Erste Lektion:** [Image Fundamentals](01-image-fundamentals/)

Fuehre diesen Befehl vom Repository-Root aus:

```bash
python3 phases/04-computer-vision/01-image-fundamentals/code/main.py
```

Dokumentiere den Befehl, den Exit-Code, HWC and CHW shapes, normalized channel statistics,
round-trip pixel difference, and interpolation roughness. The demo generates a
deterministic synthetic image and does not use the network.

**Naechster Schritt:** Explain which axis changes between HWC and CHW, then continue
to [Convolutions from Scratch](02-convolutions-from-scratch/).

Durchsuche die [vollstaendige Phase 4 Lektionsliste](../../README.md#phase-4) oder die
[phasenuebergreifende Roadmap](../../ROADMAP.md).
