# Phase 3: Deep Learning Kern

> Neural networks from first principles. No frameworks until you build one yourself.

## Diese Phase auf GitHub starten

**Voraussetzungen:** Phase 1 Linear Algebra Intuition. Phase 2 is recommended
for model evaluation vocabulary.

**Erste Lektion:** [The Perceptron](01-the-perceptron/)

Fuehre diesen Befehl vom Repository-Root aus:

```bash
python3 phases/03-deep-learning-core/01-the-perceptron/code/perceptron.py
```

Dokumentiere den Befehl, den Exit-Code, converged gate results, XOR failure of a single
perceptron, and the final two-layer XOR predictions.

**Naechster Schritt:** Explain why one linear boundary cannot solve XOR, then
continue to [Multi-Layer Networks and Forward Pass](02-multi-layer-networks/).

Durchsuche die [vollstaendige Phase 3 Lektionsliste](../../README.md#phase-3) oder die
[phasenuebergreifende Roadmap](../../ROADMAP.md).
