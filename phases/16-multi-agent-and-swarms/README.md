# Phase 16: Multi-Agent & Schwaerme

> Koordination, Emergenz und kollektive Intelligenz.

## Diese Phase auf GitHub starten

**Voraussetzungen:** Phase 14 Agent Engineering. Node.js 20+ and `npx` are
needed for the first TypeScript demo.

**Erste Lektion:** [Why Multi-Agent](01-why-multi-agent/)

Fuehre diesen Befehl vom Repository-Root aus:

```bash
npx --yes tsx phases/16-multi-agent-and-swarms/01-why-multi-agent/code/single_vs_multi.ts
```

Dokumentiere den Befehl, den Exit-Code, single-agent and multi-agent token and tool-call
totals, and one tradeoff that makes the added coordination worthwhile.

**Naechster Schritt:** Change the task, compare the two approaches again, then
continue to [FIPA-ACL Heritage and Speech Acts](02-fipa-acl-heritage/).

Durchsuche die [vollstaendige Phase 16 Lektionsliste](../../README.md#phase-16) oder die
[phasenuebergreifende Roadmap](../../ROADMAP.md).
