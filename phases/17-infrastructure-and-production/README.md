# Phase 17: Infrastruktur & Produktion

> Ship AI to the real world. Scale, monitor, optimize.

## Diese Phase auf GitHub starten

**Voraussetzungen:** Phase 11 LLM Engineering and Phase 13 Tools and Protocols.

**Erste Lektion:** [Managed LLM Platforms](01-managed-llm-platforms/)

Fuehre diesen Befehl vom Repository-Root aus:

```bash
python3 phases/17-infrastructure-and-production/01-managed-llm-platforms/code/main.py
```

Dokumentiere den Befehl, den Exit-Code, cost and latency comparison, redundancy uplift,
and a short decision record naming the workload assumptions behind your choice.

**Naechster Schritt:** Change one workload or SLA input, explain the new choice,
dann fahre fort mit [Inference Platform Economics](02-inference-platform-economics/).

Durchsuche die [vollstaendige Phase 17 Lektionsliste](../../README.md#phase-17) oder die
[phasenuebergreifende Roadmap](../../ROADMAP.md).
