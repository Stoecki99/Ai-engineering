# Phase 5: NLP, Foundations to Advanced

> Sprache ist die Schnittstelle zur Intelligenz. Master every layer.

## Diese Phase auf GitHub starten

**Voraussetzungen:** Phase 2 Lesson 14, Naive Bayes. Python 3.11+ is enough for
the first lesson.

**Erste Lektion:** [Text Processing](01-text-processing/)

Fuehre diesen Befehl vom Repository-Root aus:

```bash
python3 phases/05-nlp-foundations-to-advanced/01-text-processing/code/main.py
```

Dokumentiere den Befehl, den Exit-Code, token list, stems, lemmas, and one example where
stemming loses meaning but lemmatization preserves it.

**Naechster Schritt:** Add one sentence with punctuation and an irregular verb,
inspect the result, dann fahre fort mit [Bag of Words and TF-IDF](02-bag-of-words-tfidf/).

Durchsuche die [vollstaendige Phase 5 Lektionsliste](../../README.md#phase-5) oder die
[phasenuebergreifende Roadmap](../../ROADMAP.md).
